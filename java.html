Polymorphism Concepts Explained

Polymorphism allows objects of different classes to be treated as objects of a common superclass.

In this example:

  • A ref = new C(); - We create a C object but reference it with an A-type variable
  • ref.show(); - Calls C's show() method due to runtime polymorphism (output: "C.show")
  • Downcasting - We cast the A-type reference to B and then to C, which is safe because the actual object is C
  • ClassCastException - The last cast (C crash = (C) refA;) will fail at runtime because refA refers to an A object, not a C object
