Random User API

Try it Copy 

fetch("https://randomuser.me/api/")
  .then(res => res.json())
  .then(data => console.log(data.results[0]));

Joke API (Official Joke API)


fetch('https://official-joke-api.appspot.com/random_joke')
  .then(res => res.json())
  .then(joke => console.log(`${joke.setup} — ${joke.punchline}`));

Dog Image API


fetch('https://dog.ceo/api/breeds/image/random')
  .then(res => res.json())
  .then(data => console.log(data.message));

Weather API (OpenWeather – needs API key)


const API_KEY = 'YOUR_API_KEY';
fetch(`https://api.openweathermap.org/data/2.5/weather?q=London&appid=${API_KEY}&units=metric`)
  .then(res => res.json())
  .then(data => console.log(`${data.name}: ${data.main.temp}°C`));

Bible Verse API (Daily verse)

  .then(res => res.json())
  .then(data => console.log(`${data[0].bookname} ${data[0].chapter}:${data[0].verse} — ${data[0].text}`));
